# Lar de Patas — Frontend

HTML5 + CSS3 + Bootstrap 5 (CDN) + Bootstrap Icons. Consome a API do backend (pasta ../backend).
O endereço da API fica em `js/api.js` (constante API_PRODUCAO). Abra `index.html` com a API rodando.

- `css/style.css`: identidade visual (cores e fontes nas variáveis do topo)
- `js/ilustracoes.js`: retratos ilustrados dos animais (usados enquanto não há fotos reais)
- `js/componentes.js`: menu, rodapé e cartão de animal
- `js/api.js`: chamadas à API e sessão de login
